# Interview Practice Tickets

## 🎯 Purpose

This directory contains practice tickets simulating real interview scenarios. Each ticket represents a feature request or bug that you might encounter during the Apollo.io live coding interview.

## 📋 Ticket Structure

Each ticket includes:

1. **Requirement** - What was asked
2. **Missing Information** - What's unclear or missing
3. **Clarifying Questions** - What to ask the interviewer
4. **Technical Analysis** - Files affected, scope, risks
5. **Implementation Plan** - Step-by-step approach
6. **Acceptance Criteria** - Definition of done

## 🎓 How to Use

### Before Implementation:
1. Read the ticket
2. Identify missing information
3. List clarifying questions
4. Plan your approach
5. Get "approval" from interviewer (yourself or AI)

### During Implementation:
1. Follow the plan incrementally
2. Use AI assistance with clear prompts
3. Review code critically
4. Test thoroughly
5. Document decisions

### After Implementation:
1. Review what worked well
2. Identify what could be improved
3. Practice explaining your solution
